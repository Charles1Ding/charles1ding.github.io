💡 思考： 第一电离能是失去能量最高（最外层）那个电子所需的能量。这个电子来自哪个亚层盒子，直接决定 IE 大小：① ns 电子穿透性强、离核近 → 结合紧 → IE 高；② np 电子能量更高、被 ns² 屏蔽 → IE 较低（如 Al 的 3p < Mg 的 3s）；③ 同亚层内成对电子相互排斥 → 其中一个更易失去（如 S 的 3p⁴ < P 的 3p³）；④ 过渡金属先失去的是 4s 而非 3d。
📊 每根柱按"被失去电子所属亚层"着色并标注。可见：同一亚层的柱随 Z 升高而整体抬升；但换亚层即跳变——进入 3p（Al）比 3s（Mg）更低，进入 4s（K）骤降（新主层）。反常点 B<Be、O<N、Al<Mg、S<P 全部由"失去的亚层/轨道"解释。
💡 思考： 把纵向的"电离能高低"和横向的"亚层颜色"对应起来看——电离能不是只随 Z 单调变化，而是被被失去电子所在的亚层这一结构因素主导。悬停任意柱读取数值与亚层。
🔗 Mg vs Al： Mg 失去的是 3s 电子（穿透强、离核近、无额外屏蔽）→ IE 较高；Al 失去的是 3p 电子（能量更高、更靠外、被填满的 3s² 屏蔽）→ 尽管 Z 更大，IE 反而下降。
🔗 P vs S： P 为 3p³——三个 p 轨道各一个电子（半满，稳定）。S 为 3p⁴——某一 p 轨道出现成对电子，成对电子相互排斥 → 其中一个更易失去 → S 的 IE 低于 P。
🔗 K vs Ca（4s 新层）： K 的价电子是 4s¹，进入全新主层 n=4，离核最远、屏蔽最强 → IE 在所有元素中最低之一（419）。Ca 为 4s²，Z 更大且 4s 全满稍稳 → IE 回升。注意：Sc–Zn 失去的也是 4s（先填后失），而非 3d。
