⚗️ ChemType

Chemistry typing quiz — each falling card is a question. Type the answer (element symbol, reaction product, or term abbreviation) letter by letter before it reaches the reactor.

Three question types fall from the top:
🔹 SYMBOL — given the element name, type its formula.  Sodium → Na
🔹 PRODUCT — given the reactants + arrow, type the product.  C + O₂ → CO₂
🔹 ABBREV — given the term, type its abbreviation.  Activation energy → Ea

How to play:
• Type the first letter of the answer to lock onto a card (it glows green).
• Finish typing the answer = points + combo. Let one breach = lose a life.
• A pink BOSS card (long equation) appears now and then — type it fully or lose 2 lives.
• When a card is destroyed or breaches, its correct answer flashes so you learn it.
• Speed & spawn rate ramp up each stage. How high can you score?
